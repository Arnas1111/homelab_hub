Programming
One instruction per line. Valid code updates the canvas.

Syntax
when "Motion sensor".occupancy == true
during 18:00..05:30
do "Hall light".power = on

when "Motion sensor".occupancy == false
during 18:00..05:30
wait 5s
if "Motion sensor".occupancy == false
do "Hall light".power = off
Each when starts a separate path in one automation. during 18:00..05:30 checks local time, including midnight. Use if for a later state check, at 18:00 for a clock trigger, or item "Device" to change device context.

PostgreSQL history storage

Connect an existing database. Collection runs even when the Hub is closed in your browser.

The database must already exist. The Hub creates its own homelab_hub schema on first collection. Retention automatically deletes this Hub's older samples; disabling collection keeps existing history. Credentials are stored in local appdata.

Use a hostname reachable from the Hub container, not localhost. Verified TLS uses libpq's root certificate configuration (PGSSLROOTCERT). At 30 seconds, collection stores about 2,880 snapshots per day.
